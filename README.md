## Overview

### The challenge

Users should be able to:

- Add their email and submit the form
- See a success message with their email after successfully submitting the form
- See form validation messages if:
  - The field is left empty
  - The email address is not formatted correctly
- View the optimal layout for the interface depending on their device's screen size
- See hover and focus states for all interactive elements on the page

### What I learned

This is the first time I have worked with forms and their validation in this project. I immediately disabled browser validation because I was interested in doing my own custom validation.

### Continued development

In this job, I had only one form with one field to fill out. In the future, it would be interesting for me to work with a large number of forms and find out what else can be done with them, and what feedback they provide.

### Useful resources

- [https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Form_validation] - very cool and useful documentation on forms and their verification. Based on it, I implemented the form in my project.

### AI Collaboration

It was in this work that I first came across forms. Thanks to the documentation and, to no lesser extent, AI, I learned the basics of forms. The AI gave me the base in its brief form. Later, as needed, I specifically consulted the documentation.
